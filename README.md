# OM Auto：Pad 标号与空间抽样

用于 AlScN 等薄膜的 OM 图像辅助标号、版图登记、按区域与重复版图分层选点和人工电学结果统计。也支持限定几何规格选点。本仓库归档 V1 源码；原始图片、样品数据库与测试产物不上传。OM 候选检测是辅助功能，必须人工核验。

## 模块与数据结构

- `om_auto/core.py`：面积、几何规格分组、可复现的分层随机抽样、Wilson 区间、Pr/Ec 描述统计。
- `om_auto/store.py`：SQLite。`samples` → `regions`（区域与版图类型）→ `layout_units`（区域内重复版图及其行列）→ `pads`（版图内 Pad 行列）→ `measurements`；`plans` 保存选点清单、区域分配和种子；`templates` 保存版图；`images` 保存 OM 关联。
- `om_auto/vision.py`：对比度阈值和连通域生成圆形/方形候选位置，不自动把候选认定为真实 Pad。
- `om_auto/server.py` 和 `static/`：本地 HTTP API 与浏览器界面。

## 启动

需要 Python 3.10+。当前 WSL 已安装依赖；其他机器可先运行 `python -m pip install -r requirements.txt`。

```bash
cd OM_auto
python run.py
```

打开 `http://127.0.0.1:8765`。默认只监听本机；数据写入 `data/om_auto.sqlite3`，上传图片保存在 `data/images/`。可设置 `OM_AUTO_DATA` 修改数据目录。

若 OM 已在本机或已挂载的 NAS 目录，可只读导入选定图片（源文件不会改变）：

```bash
python import_om.py --sample '54#' --dir '/path/to/54#/00_OM' --pattern '30X-1.jpg'
```

文件名为 `ZHENGPIAN.jpg` 时自动设为主图，也可在界面手动指定。重复运行导入脚本时，同内容图像会跳过。仓库不附带真实样品图片或数据库；首次运行后请自行导入。

运行模拟样品（3 Region × 9 Unit × 4 Pad = 108 Pad，其中 6 个有模拟结果）：

```bash
python make_demo.py
```

模拟样品 ID 默认为 `DEMO-3R`；仅运行一次，重复运行会因相同样品 ID 被拒绝。可用 `--sample` 指定新 ID。该脚本生成 3 个区域、每区 9 个重复版图、每版图 2×2 个 Pad。到“算法选点”勾选 R1/R2/R3、填写 9 个测点和固定种子，然后下载任务表；需要同规格时可切换选点方式。

## 使用顺序

1. 新建样品；先导入整片 `ZHENGPIAN.jpg` 作为主图，其余倍率照片作补充。可导入 [Pad 表](templates/pads.csv)，或在完整缩略图上为每个区域画框并填写区域 ID，可逐框或一次识别全部，再在放大图中查看，核对规则格点并完成删点、补点后，核对主图自动读取的标尺（无法读取时手动填写 µm/像素），点击“保存全部已核对候选为 Pad”批量入库；规则点使用行列编号，人工补点使用 U-MANUAL/M 编号。缺失尺寸的 Pad 不进入几何分组。版图模板可保存、应用或从“版图模板”下拉框中选中后删除；删除模板不会移除已应用到样品的 Pad。
2. 在“算法选点”查看空间图：绿色为非纯布局推断的可用 Pad，灰色空心为纯布局推断，灰色实心为已测，红色为排除，虚线框表示 Region。可缩放、隐藏已测/排除 Pad；选中测点显示为细红色虚线圈，普通 Pad 缩小以便看清主图。勾选区域、数量和种子后生成测试任务 CSV；需要时切换为按几何规格。点击图上的 Pad 可从当前清单取消或加入，调整后另存为新方案，原方案和 CSV 保留。历史方案可重新在图上查看。没有主图时显示坐标示意图。
3. 测试后导入 [结果表](templates/measurements.csv)。Pad ID 必须能匹配；未知 ID 会拒绝整批导入。原始输入行保留在数据库 `original_json`。
4. 在“统计分析”选择几何组和评价区域，查看有效率、Wilson 95% 区间、击穿率、有效 Pad 的 Pr/Ec 与区域分布。

右上角可删除当前样品；确认框会先列出关联的 Pad、测试记录、选点方案和图片数量。删除后样品从下拉列表移走，但数据保留，在“样品与版图 → 已删除样品”中可恢复。此操作不删除原始 OM 文件，也不清除电学记录。

## 数据字段与约定

`S001:R1:U1:C180` 中，`S001` 是**样品 ID**，`R1` 是区域，`U1` 是区域内的重复版图，`C180` 是版图内 Pad 的局部标签；`S` 不是区域。推荐的新编号为 `S001:R1:L_A:U01:r03c05-C180`：`L_A` 是版图类型，`U01` 的位置由 `unit_row/unit_col` 标明，`r03c05` 是该版图内第 3 行第 5 列的 Pad。同一区域只能登记一种版图类型；不同区域可使用不同类型。旧四段式 Pad ID 保留，不会自动改名或断开已有电学记录。

Pad 表必填：`pad_id, region_id, layout_unit_id, pad_local_id, shape`。建议填写 `layout_type_id`、`unit_row/unit_col` 和 `pad_row/pad_col`；行列从 1 开始，必须成对填写，单元内不能有两个 Pad 占用同一行列。未提供版图类型的新区域默认为 `L1`，旧数据迁移为 `unknown`，需后续核对。`shape` 为 `circle/square/other`。圆形需 `diameter_um`；方形需 `width_um`（可再填 `height_um`）。坐标 `x,y` 用于空间图和选点分散，导入时坐标单位须保持一致；若坐标取自主图，还需填主图的 `image_id`，选点才会准确叠加到整片图。`usable=0` 必须填写 `exclusion_reason`。`area_source`、`area_confidence` 用于记录尺寸溯源。模板 CSV 的示例 Pad ID 只是字段演示，应改成自己的编号。

结果表必填：`pad_id,status`。`status` 为 `valid/no_response/breakdown/leakage/test_error`。`valid` 需填写 `pr_uc_cm2`（µC/cm²）及 `ec_mv_cm`（MV/cm）；其他状态不得将 Pr/Ec 记为 0。`reviewed=0` 的有效记录不纳入有效指标统计。还可记录 `measured_at,protocol_id,pulse_v,pulse_width_us,interval_us,breakdown_v,max_voltage_v,leakage_a_cm2,invalid_reasons,raw_path`。历史数据没有可靠 Pad 对应关系时，不可虚构 Pad ID 导入。

整片主图是空间定位的唯一基准；补充图用于观察局部细节，不会自动与主图对齐。“Pad 分布”在有整片主图时按主图原始像素坐标和长宽比叠加已保存 Pad，显示各区域检测框、名称和相对位置；支持整片/单区域缩放，点击 Pad 会显示它在所属重复版图内的序号与正式编号，灰色空心点表示仅由版图推断。整片图先在完整缩略图上为多个区域分别画框；区域框保存在样品数据库中，可单独删除或重新加载，添加或定位框时放大图自动缩放到该框，并可逐框或一次识别全部。识别候选只保留在当前页面；人工删点与补点保存在 `candidate_edits` 表，重新识别时继续生效，可在页面撤销。选中错误候选后点“删除选中候选点”；点击“点击放大图补点”后在遗漏 Pad 中心点击即可补点，尺寸默认取同区域候选中位数，也可填写宽高。放大图默认只显示细小的候选中心点，并隐藏已保存 Pad；可分别打开“显示尺寸轮廓”“显示已保存 Pad”，也可关闭候选标记直接看原图。绿色为阵列支持候选，紫色为规则补漏点，橙色为离网待复核候选，蓝色为人工补点。区域标签显示在放大图外。全部区域完成规则版图识别并人工核对后，系统优先读取主图左下角标尺的文字和端点长度并自动填入 µm/像素，核对后即可批量保存当前候选；已有同编号 Pad 会跳过，位置冲突或已保存点不在当前候选中会提示核对，系统不会自动覆盖或删除。单点编号入口保留在“高级”区域。删除区域框不会删除已保存 Pad。任一边超过 2000 像素的范围自动分块识别，识别时显示逐区域进度。候选不再按前 500 个截断，识别器先拟合重复版图块和行列间距，再生成完整的版图格点。对 54# 主图，R1 为 2×3 个重复版图，每版图 12×12 大 Pad＋底部 2×24 小 Pad；R2 为 3×3 个重复版图，每版图顶部 2×24 小方 Pad＋12×12 大 Pad；R3 为 3×3 个重复版图，每版图 12×12 大 Pad；R4 为四条带状版图，每条由四组各两行、尺寸逐级增大的 Pad 组成。每个格点带版图号、Pad 行列及近似像素尺寸；绿色有原始检测支持，紫色有局部图像信号，灰色仅由布局推断，后两者须人工核验。规则版图的橙色原始散点不进入格点结果；无法可靠拟合规则版图时保留原检测方式。格点数量是版图模型位置数，不是 Pad 实物确认数。OM 候选检测使用局部背景对比、连通域和阵列邻近支持，对标尺、文字、划痕和复杂背景可能误检；候选序号只是图上标记，正式 Pad ID 需人工确认。圆/方预测与边框尺寸都需人工检查。高倍率带测量线的图片可能检测不到 Pad，此时可点击主图并手动输入像素宽高补充候选。确认候选时须有有效的 **µm/像素**（自动读取或人工校正）；图上 `x,y` 保存为主图像素坐标。

## 抽样和统计解释

“算法选点”默认按区域与重复版图选点：勾选 R 区域后，区域间尽量平均分配；区域内优先选择不同重复版图，再选择距离已有测点较远的位置。无需先填写几何尺寸。也可切换为按几何规格，限定到同规格 Pad。已测和排除点默认不参与；“纳入灰色空心推断点”默认勾选，纯布局推断点会进入候选清单，使用前须人工逐点核验。不希望纳入时可取消勾选。种子、模式、区域、完整 Pad 清单保存在 `plans`。所选区域没有合格 Pad 时会提示。当前区域分配为等额设计；当区域 Pad 总数差异很大时，汇总的有效率和 Wilson 区间是**已测 Pad 的描述统计**，不能视作按总体库存加权的无偏整片估计。混合几何规格时 Pr/Ec 不宜解释为单一规格性能；仅测一部分区域时，界面提示结论范围。

## 测试

```bash
cd OM_auto
python -m pytest -q
```

真实整片图片的隔离端到端测试可复现为：

```bash
python real_image_e2e.py \
  --image '/path/to/54#/00_OM/ZHENGPIAN.jpg' \
  --supplement '/path/to/54#/00_OM/30X-1.jpg'
```

这个测试脚本目前按 `54#` 的版图编写，需提供相应整片图；运行后在 `data/e2e_real_时间戳/` 创建隔离数据库、两轮任务表、整片图选点图和机器可读报告。暂定 Pad 和模拟 PUND 不会写入正常数据库。要在浏览器查看生成的隔离测试库，可设置 `OM_AUTO_DATA` 为该次输出目录再运行 `python run.py`。几何识别结果仍需人工核对。

## 当前范围与限制

已实现 P0 的样品/版图/Pad、CSV/XLSX 导入、模板复用、空间图、几何分组、分层选点、任务导出、人工结果导入、基础统计和 Wilson 区间；另有 OM 半自动候选确认。

尚未实现 P1 的自适应补测决策、重抽样验证、正式报告及复杂的空间/加权方差估计；界面暂不支持编辑已有 Pad；OM 候选已支持批量入库。共享 NAS 本身未能从此 WSL 会话直接读取；本机 PVD 备份的 `54#`、`51#`、`70#` 的 30X OM 图用于初步核验，候选数随图像变化较大，需要人工剔除误检。整片主图上的细小 Pad 仍需核验结果，阵列支持度不等于真实 Pad 置信概率；150X 带测量线图未能可靠自动检测。
